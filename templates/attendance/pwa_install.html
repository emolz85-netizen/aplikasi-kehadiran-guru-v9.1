Pasang Aplikasi Kehadiran Guru

Gunakan sistem seperti aplikasi biasa dari skrin utama Android, iPhone, iPad atau komputer.

🤖 Android

  1. Buka menggunakan Chrome atau Edge.
  2. Tekan butang Pasang yang muncul.
  3. Jika tidak muncul, buka menu ⋮ dan pilih Pasang aplikasi atau Tambah ke skrin utama.
  4. Tekan ikon Kehadiran pada skrin utama.

🍎 iPhone / iPad

  1. Buka menggunakan Safari.
  2. Tekan ikon Kongsi.
  3. Pilih Add to Home Screen / Tambah ke Skrin Utama.
  4. Tekan Add / Tambah.

Web Push memerlukan aplikasi dipasang dan iOS/iPadOS 16.4 atau lebih baharu.

💻 Windows / Mac

  1. Buka menggunakan Chrome atau Edge.
  2. Tekan ikon pemasangan pada bar alamat.
  3. Pilih Install / Pasang.
  4. Aplikasi dibuka dalam tetingkap sendiri.

✅ Kelebihan

  • Ikon pada skrin utama.
  • Paparan penuh tanpa bar alamat.
  • Notifikasi push.
  • Halaman luar talian asas.
  • Kemas kini automatik.
